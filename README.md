Informe del Proyecto: DiviMisterio
Nombre del videojuego:
DiviMisterio
Descripción del juego:
DiviMisterio es un videojuego educativo/interactivo desarrollado en Unity, ambientado en un museo ficticio donde ha ocurrido el robo de un cuadro valioso. El jugador debe explorar distintas salas, hablar con personajes y recolectar pistas para descubrir quién es el verdadero culpable entre tres sospechosos principales.
Herramientas utilizadas:
Motor de desarrollo:Unity
Lenguaje de programación: C#
Control de versiones: Git y GitHub
Enlace al repositorio de GitHub:
https://github.com/murdocezgranada/Divimisterio

Estructura del repositorio:
	Assets: Contiene todos los recursos del juego (scripts, escenas, prefabs, sprites, etc.)
	Packages: Información de paquetes usados en el proyecto Unity
	ProjectSettings: Configuraciones del proyecto (input, calidad, escenas del build, etc.)
	.gitignore: Archivo que indica qué carpetas deben ser ignoradas por Git
	.vscode y .vsconfig: Configuraciones del editor Visual Studio Code/Visual Studio
Rama activa del repositorio:
DiviMESPEJO — contiene la versión más reciente del proyecto.
